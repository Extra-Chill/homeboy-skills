# Homeboy Skills

Agent skills for [Homeboy](https://github.com/Extra-Chill/homeboy) — config-driven CLI for multi-project deployment, versioning, and development automation.

## Skills

| Skill | Description |
|-------|-------------|
| `homeboy` | Core Homeboy operations — deployment, versioning, project management, embedded docs |

## Installation

Manual install:

```bash
git clone https://github.com/Extra-Chill/homeboy-skills.git /tmp/hb-skills
cp -r /tmp/hb-skills/homeboy/ /path/to/skills/
```
